# Фича: экран «Сегодня» на моковых данных
Что: страница /today со списком приёмов лекарств на сегодня и кнопкой «Дал».
Для кого: владелец питомца, который даёт лекарство по курсу.
Сценарий: открыть /today → увидеть приёмы на сегодня по времени → нажать «Дал» у приёма → карточка показывает, что лекарство дано.

Дано: в моках один курс (питомец «Барсик», 2 препарата), на сегодня 3 приёма — 09:00, 14:00, 21:00.
Когда: открыта страница /today.
Тогда: видны 3 карточки по возрастанию времени; на каждой название препарата, доза, время и кнопка «Дал».

Дано: открыта /today, приём 09:00 не отмечен.
Когда: нажата «Дал» у приёма 09:00.
Тогда: карточка показывает «Дано в ЧЧ:ММ» (время нажатия), кнопки «Дал» на ней больше нет; остальные карточки не изменились.

Чего не делать: не подключать Supabase и не сохранять отметки между перезагрузками; не ставить пакеты; не менять components/ui/button.tsx и components/course-card.tsx; не писать цвета и размеры напрямую — только токены из app/globals.css; на стартовой странице добавить только ссылку на /today.
